This is my Final Year Project named **RELIV**, an AI health companion application designed to monitor user well-being, integrate sensor data, and provide personalized health insights in real time. I developed this application to bridge the gap between personal healthcare tracking and intelligent AI assistance, earning the **Best Final Year Project achievement award**.

## Features

- **AI Health Companion**: Intelligent assistant that processes health metrics and offers personalized guidance.
- **Sensor Integration**: Seamlessly connects with device sensors to track physical activity and vital metrics.
- **Real-Time Data Sync**: Powered by Firebase for instantaneous data updates and secure cloud storage.
- **User Dashboard**: Clean, responsive, and intuitive interface designed with Flutter and Material design guidelines.
- **Secure Authentication**: Robust user sign-up and authentication workflows for data privacy.

## Tech Stack

- **Frontend & Mobile**: Built using **Flutter** and **Dart** for cross-platform performance across Android and iOS.
- **Backend & Database**: Leveraged **Firebase** (Firestore, Authentication, and Cloud Functions) for real-time backend synchronization.
- **Architecture**: Follows **Clean Architecture** patterns to maintain decoupled, testable, and scalable code.
- **State Management**: Utilized modern state management solutions to handle complex UI states efficiently.

## Implementation

### Frontend & UI

- Modular **Flutter** widgets designed for reusable and responsive layouts.
- State management organized cleanly to separate business logic from UI components.

### Backend & AI Integration

- **Firebase** integration for secure cloud data storage and fast user authentication.
- Custom logic to process and handle sensor streams for real-time health monitoring.

## How It Works

1. **Onboarding & Auth**: Users securely log in or create an account managed via Firebase.
2. **Dashboard Overview**: Displays real-time health statistics, sensor readings, and AI insights.
3. **AI Companion Interaction**: Users can interact with the AI helper for wellness suggestions and data analysis.
4. **Data Tracking**: Continuously monitors physical metrics using built-in smartphone sensors.

## Challenges Faced

- Handling asynchronous data streams from device sensors without performance bottlenecks.
- Ensuring smooth, real-time synchronization with Firebase under varying network conditions.
- Structuring clean state management for complex reactive UI flows.

## Future Enhancements

- Integrating wearable device SDKs (like smartwatches) for direct health metric syncing.
- Expanding AI capabilities for predictive health trend analysis.
- Introducing a companion web dashboard for desktop review.
