This is a fast food and recipe discovery application named **Quick Meals**, designed to help users find, filter, and prepare meals quickly based on available ingredients and dietary preferences. I developed this app to showcase clean mobile UI design, smooth navigation, and predictable event-driven state handling using **BLoC and Cubit**.

## Features

- **Recipe Discovery**: Browse through a wide variety of quick recipes categorized by cuisine, preparation time, and dietary requirements.
- **Advanced Search & Filtering**: Instant search capabilities allowing users to filter dishes by ingredients, calories, or cooking speed.
- **Favorites & Meal Planning**: Save preferred recipes to a personalized favorites list managed through structured state management.
- **Step-by-Step Instructions**: Interactive cooking mode displaying clear ingredient lists and sequential cooking instructions.
- **Cloud Sync & Auth**: Secure user authentication via Firebase to sync saved favorites across devices.

## Tech Stack

- **Frontend & Mobile**: Built using **Flutter** and **Dart** to ensure a smooth, cross-platform experience across Android and iOS devices.
- **State Management**: Implemented **BLoC and Cubit** to handle complex user interactions, asynchronous data loading, and predictable state transitions.
- **Database & Cloud**: Powered by **Firebase** for user authentication and cloud-based recipe data synchronization.
- **Architecture**: Organized following clean component structures and reactive design patterns.

## Implementation

### Frontend & UI

- Custom **Flutter** widgets designed for dynamic grid layouts, recipe cards, and immersive detail views.
- Smooth transitions and reactive UI builders (`BlocBuilder` and `BlocConsumer`) to handle loading, success, and error states seamlessly.

### State Management with BLoC & Cubit

- Utilized **Cubit** for simpler UI states (like category filtering and favorites toggling) and **BLoC** for complex event-driven workflows (like search queries and authentication streams).
- Decoupled business logic entirely from the presentation layer to ensure high testability and maintainability.

## How It Works

1. **User Authentication**: Users log in or sign up securely via Firebase authentication managed by authentication cubits.
2. **Browse & Search**: Events are dispatched to search blocs to fetch and filter trending recipes instantly.
3. **Recipe Details**: Tapping a recipe opens a detailed view with ingredients, cook time, and step-by-step instructions.
4. **Bookmark Favorites**: Users can tap the favorite icon to dispatch a state update, instantly storing recipes to their personal profile.

## Challenges Faced

- Managing complex asynchronous data streams and network states efficiently using BLoC event transformers.
- Structuring robust state transitions for filtering multiple recipe categories simultaneously without UI glitches.
- Designing a responsive layout that looks equally polished across various mobile screen sizes.

## Future Enhancements

- Integrating an AI-powered "What's in my fridge?" ingredient scanner to suggest meals automatically.
- Adding a grocery shopping list generator based on selected weekly recipes.
- Introducing user-submitted recipe uploads and community rating systems.
